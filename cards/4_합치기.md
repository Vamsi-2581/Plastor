# 단계 4. 합치기
목표: 부위가 본체와 이어진 한 메시. 떠 있는 조각이 없다.
규칙:
- 합치기는 `python build.py --spec build.json --from parts`(부위 박기 → Decimate + Boolean EXACT → 찌꺼기 청소). 임시 코드로 합치지 않는다.
- 떠 있는 조각은 부위가 본체에 닿지 않는다는 뜻이다. 위치 문제(트레이스)인지 헐이 비었는지 먼저 본다. 메시를 손으로 옮기지 않는다.
- 합친 메시는 `model_loop.py check --merged <OBJ>` 로 몸 수를 센다. 겹쳐 있기만 하면 복셀로는 닿아 보인다.
끝 조건: 떠 있는 조각 0, 열린 변 0.

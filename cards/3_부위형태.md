# 단계 3. 부위 형태(뿔·귀·꼬리)
목표: 부위마다 재투영이 맞고, 3/4 에서도 그럴듯한 단면을 가진다.
규칙:
- 부위는 비주얼 헐(`harness/hull.py`, master='front'). 헐은 두 뷰 실루엣은 맞지만 단면이 상자가 된다.
- 길쭉한 부위(뿔·꼬리)는 build.json 부위에 `"method": "round"`(둥근 헐: 실루엣은 헐과 같고 단면은 둥긂). 표면이 복셀 계단으로 남는 것은 알려진 한계다. build_round(뼈대+공)는 실루엣 0.83 이라 쓰지 않는다.
- 같은 재질 하위 부위(뿔+밑동)는 한 물체로 헐을 만든다.
- 길쭉한 부위는 `python -m harness.blender_view <OBJ> <폴더>` 로 위·3/4 그림을 본다(단면 채움비가 휜 뿔을 놓친 적 있음).
끝 조건: 부위 모든 뷰 IoU ≥ 0.95, 상자 단면 없음(또는 사람에게 보고).

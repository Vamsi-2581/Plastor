# 단계 5. 리깅 준비
검사기: `harness/rig_check.py`(build 의 rig 단계). 합친 메시에 시험 뼈대 3개(목·머리·턱)를 자동 배치하고 자동 가중치(ARMATURE_AUTO)를 건다.
- PASS 조건: 연결 성분 1, 열린 변 0, 가중치 0 정점 비율 ≤ 0.01, Bone Heat 경고 없음.
- 좌우 비대칭도(X 거울 최근접 거리 평균 / 대각선)는 보고만 한다(0.01 이하면 대칭). 판정에 넣지 않는다.
- FAIL 이면 아래 실패 이유를 고친다: 덩어리·열린 변은 단계 4(합치기)로, 가중치 0 정점은 메시 품질(겹침·뒤집힌 면·너무 가는 부위)로 돌아가 본다.
- rig_check.json 이 없으면 UNKNOWN(rig 단계를 먼저 돌린다).
- 다음 단계: Rigify 사족 메타릭 리깅(아직 없음). 자동 리깅(UniRig 등)은 학습 모델·GPU 라 사용자 승인이 필요하다.

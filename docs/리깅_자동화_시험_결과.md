# 리깅 자동화 시험 결과 (합성 4족 도형, 2026-10-28)

코드 `experiments/rig_auto/rig_test.py`, 원자료 `experiments/rig_auto/result.json`. Blender 5.2.1 내장 기능만, 새 설치 없음. 격리 폴더에서만 실행.

## 시험 내용
- 닫힌 부품 8개(몸통·목·머리·꼬리·다리 4)를 합성. 이음매는 약간 겹치게 만듦.
- **공용 골격 템플릿 = 뼈 이름과 부모만**(좌표 없음). **뼈 위치는 규칙으로 계산**: 부품 주축(PCA)의 양끝 중 부모 부품 중심에 가까운 쪽이 관절.
- 방식 A 부품 단위(부품 하나 = 뼈 하나, 가중치 없음), 방식 B 합친 메시 + 내장 자동 가중치(`ARMATURE_AUTO`).
- 같은 포즈(목 35°, 머리 20°, 앞다리 −45°, 뒷다리 40°, 꼬리 −40°)를 주고 숫자로 측정.

## 결과 (실행 검증됨, 단 이 합성 도형 하나·포즈 하나)
| 항목 | A 부품 단위 | B 자동 가중치 |
|---|---|---|
| 리그 연결 후 정점 이동 | 3e-7 (없음) | 2e-7 (없음) |
| 가중치 없는 정점 | 해당 없음 | 0 |
| 부품 부피 변화 / 전체 부피 비 | 2.5e-7 (강체) | 0.973 (2.7% 손실) |
| 변 길이 비 최소~최대 | 해당 없음 | 0.67~1.43 (0.5 미만·2 초과 0개) |
| 이음매 최소 거리 기본→포즈 | 최대 0.048H (기본 0.02~0.03) | 해당 없음(한 덩어리) |
| 정점당 영향 뼈 수 최대 | 1 | **5** |

## 판정 (이 시험 범위에서만)
- **"규칙으로 뼈 배치 + 자동 가중치" 자체는 동작한다.** 가중치 누락 0, 붕괴 없음, 부피 손실 2.7%.
- 부품 단위는 틈이 최대 0.048H 열린다(몸 높이 약 2H 기준). 3등신 캐릭터 8방향 스프라이트에서 보일지는 케라투라 쪽 판단이 필요하다.

## 발견한 문제 (해결 과제)
1. **뼈당 정점 영향 5개**: 게임 엔진은 보통 4개 제한. 자동 가중치 뒤 상위 4개로 줄이고 재정규화 단계가 필요하다(미구현).
2. **둥근 부품(머리)은 PCA 주축이 불안정**: 머리 뼈가 앞뒤로 길게 잡혔다(0.93→1.77). 관절 규칙은 부품 형상이 아니라 **이웃 부품과의 접촉점**(이음매)으로 정하는 편이 맞다.
3. 합친 메시의 부위 구분은 이 시험에서 부품 경계로 해결했지만, 실제 하네스 출력(한 개의 관 모양 메시)에서는 **고리 높이 범위를 뼈에 대응시키는 규칙**이 따로 필요하다.

## 한계
- 눈으로 보는 렌더 확인을 하지 않았다(숫자만). 합성 형상 하나, 포즈 하나. 일반 법칙으로 승격하지 않는다.
- 케라투라가 실제로 부품 단위 리그를 쓰는지, 스키닝이 필요한지는 미확인.
- Godot 4 내보내기(glTF)와 애니메이션 재사용은 시험하지 않았다.

## 정정 (렌더 확인 후, `experiments/rig_auto/rig_sheet.png`)
렌더를 보니 **방식 B(자동 가중치)의 포즈가 방식 A(부품 단위)와 거의 같다.** 부품이 서로 떨어진 별개 덩어리라 열 확산 가중치가 덩어리를 넘지 못하고 각 부품이 가장 가까운 뼈에 통째로 붙었다. 그래서 위 표의 "붕괴 없음·부피 손실 2.7%"는 **부드러운 굽힘이 잘 된다는 증거가 아니다.** 목 아래 이음매가 잘려 보이고 목·머리 방향도 어색하다.
- 판정 수정: "자동 가중치가 동작한다" → **"가중치 누락 없이 연결되지만, 이음매가 이어진 한 덩어리 메시에서 부드럽게 굽는지는 이 시험으로 확인하지 못했다"(UNKNOWN).**
- 다음 시험은 목·다리가 몸통과 이어진 한 덩어리 메시(하네스 출력 형태)로 해야 의미가 있다.

## 2차 시험: 이어진 한 덩어리 메시 (`experiments/rig_auto/rig_test2.py`, `result2.json`, `rig_sheet2.png`)
방법: 부품을 불리언 합치기 + 복셀 리메시(0.045)로 **한 덩어리**(연결 덩어리 1, 열린 변 0, 정점 6148)로 만든 뒤 자동 가중치, 영향 뼈 4개 제한(`vertex_group_limit_total`). 관절은 **부모 부품과 가장 가까운 정점 쌍의 가운데**(접촉점 규칙)로 바꿨다. 목·머리는 아래로 숙이는 포즈(1차의 방향 문제는 부호 실수: +X 회전이 위로 드는 방향이었다. 리그 버그 아님).
- 가중치 없는 정점 0, 정점당 영향 뼈 최대 4(제한 성공), 두 뼈 이상 섞인 정점 48.4% → **부드러운 굽힘이 실제로 일어남**(렌더에서 목이 휘고, 머리가 숙고, 다리가 움직임).
- 전체 부피 비 1.008. 변 길이 비 최소 0.55, 최대 7544(4개 변): 리메시가 만든 길이 거의 0인 변으로 추정(미확인). 0.5 미만·2 초과 4개.
- 판정(이 합성 형상·포즈 하나에서만): **"공용 골격 + 접촉점 규칙 + 자동 가중치 + 4개 제한"은 동작.** 1차의 UNKNOWN 해소. 이음매 주변 덩어리짐(다리 안쪽·몸통 아래)이 3/4 렌더에서 보인다 → 가중치 품질 개선 여지.
- 미시험: 하네스 실제 출력, glTF 내보내기·Godot 로드, 애니메이션 재사용, 여러 종 골격 템플릿.

# 무료 도구 조사 (2026-10-29)

사용자 요청: "도움되는 무료 도구들도 조사해보는게 어때". 기준: 무료, 내 컴퓨터(CPU)에서 돌아감, 하네스의 어느 단계에 쓰는지.
이미 쓰는 것: Blender 5.2(번들 Python·numpy), vtracer, scipy, scikit-image, opencv-python-headless, Pillow(.vendor).

## A. 설치 없음: Blender 안에 이미 있음

| 도구 | 쓸 곳 | 기대 | 확인 상태 |
|---|---|---|---|
| 커브 + 베벨 단면(또는 Geometry Nodes Curve to Mesh) | 단계 3 뿔: 중심선을 따라 타원 단면을 쓸기. 단면 폭은 정면·옆 트레이스에서 잰다 | '상자 단면'(헐) 해결. 남은 과제였던 타원 단면 쓸기를 직접 만들 필요가 없다 | Blender 기본 기능. 하네스 연결은 미구현 |
| Skin 수정자 | 크리처 본체·다리: 뼈대 점 + 점마다 반지름 → 메시. "Create Armature"로 뼈도 만든다 | 고리 케이지가 어려운 팔다리·꼬리. 리깅 뼈가 같이 나온다 | Blender 기본 기능. 미시험 |
| Rigify 사족 메타릭(Basic Quadruped, Horse, Wolf 등) | 단계 5 리깅: 메타릭 뼈를 모델에 맞춘 뒤 Generate Rig, 자동 가중치 | 리깅 검사기가 없는 단계 5를 학습 모델 없이 시작 | [Blender 설명서](https://docs.blender.org/manual/de/5.2/addons/rigify/basics.html). 1단위 = 1m 가정 주의 |
| Remesh(복셀·QuadriFlow) | 단계 4 뒤: 헐의 복셀 줄무늬, 변형에 맞는 사각면 | 줄무늬 제거, 리깅 전 면 정리 | Blender 기본 기능. 실루엣이 얼마나 바뀌는지는 재야 함 |
| Boolean 수정자(지금 EXACT 사용) | 단계 4 합치기 | 이미 씀 | Manifold 해법이 Blender 5.2에 있는지는 확인 못 함(UNKNOWN) |

## 추천 순서(가설, 각각 합성 장면으로 검증 후 채택)

1. **커브 베벨로 뿔 타원 단면 쓸기**(설치 없음). 반증 조건: 합성 둥근 뿔에서 재투영 IoU 가 헐보다 0.01 넘게 떨어지거나 단면 채움비가 0.85 를 넘으면 기각.
2. **Rigify 사족 메타릭으로 단계 5 시작**(설치 없음). 검사기부터: 뼈가 메시 안에 있는지, 자동 가중치가 모든 정점에 붙는지.
3. **Blender MCP**(승인 필요): 3/4·위·아래 화면을 루프 검사에 붙인다. 모델링은 하네스 명령으로만(좌표 눈대중 금지 유지).
4. **trimesh**(승인 필요): 3D 검사의 닫힘·성분 검사를 기존 도구로 바꾼다.

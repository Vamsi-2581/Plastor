# 계획: 트레이싱 도구 섞어 쓰기 (2026-10-29)

> 정정(2026-10-30): 단계 2 의 '작은 부위(15% 이하) SAM 자동'은 FAIL 로 꺼졌다(수정_기록 43). SAM 은 사양 `method_by_part` 로 부위마다 정한다.

사용자 요청: "그걸 어떻게 섞어쓸건지 계획해봐". 대상 도구: 우리 규칙(배경 견본·색 군집·영역 선택), ToonOut(애니 캐릭터 배경 지우기, MIT), SAM 2.1(작은 부위), LLM(판단), 검사기.
원칙: 도구마다 잘하는 일만 맡기고, 두 도구가 다르게 말하는 곳은 **증거로 가른다**. 갈라지지 않으면 UNKNOWN 으로 남기고 LLM 이 그림을 본다. 비싼 도구는 필요할 때만 부른다(조건부 분기).

## 단계와 맡는 쪽

| 단계 | 기본 | 더하는 도구(조건) | 섞는 규칙 |
|---|---|---|---|
| 0 배경 | 우리 규칙: 가장자리 배경 견본 + 가장자리와 이어짐 | **ToonOut**: 배경이 한 색이 아닐 때만(가장자리 견본 색이 둘 이상, 또는 다각형 밖 남은 조각이 많을 때) | 둘 다 배경 → 배경. 둘 다 전경 → 전경. **엇갈린 곳**: 우리는 배경·ToonOut 은 전경 → 그 픽셀이 배경 견본 색에 가까우면 배경, 아니면 전경. 우리는 전경·ToonOut 은 배경 → LLM 거친 다각형 안이고 합의된 전경과 이어지면 전경(가는 뿔 끝 보호), 아니면 배경. 엇갈린 넓이를 보고하고, 전경의 2% 를 넘으면 UNKNOWN(LLM 이 겹침 그림 확인) |
| 1 재질 | 색 군집(Lab) + 기준색 최근접 | **LLM 두 가족**(Claude·Codex): "목록에 없는 물감 번호는?" 한 질문 | 두 가족이 같은 번호·부위만 새 재질 |
| 2 부위 | 우리 영역 선택(다각형 + 재질 경계) | **SAM**: 작은 부위(거친 다각형이 가장 큰 부위의 15% 이하) | SAM 넓이가 우리 방식의 70% 미만이면 우리 방식. 겹친 픽셀은 그림 근거(SAM) 쪽 |
| 3 검사 | 독립 검사(정면·옆 높이, 좌우), 3D 재투영, 카드 | 같은 진단 2번이면 조사 단계 | 판정 넷(PASS·FAIL·UNKNOWN·ERROR) |

## 검증 계획(돌리기 전에 정한 기준)

1. **정답 있는 체크무늬 벤치마크를 먼저 만든다**: `bench/scene.py` 에 체크무늬 배경 변형(회색·흰 칸 + 칸 사이 중간색 + 4배 확대 번짐 흉내). 지금까지 체크무늬는 새 머리 한 장(정답 없음)뿐이다.
2. 비교 셋: (가) 우리 규칙만 (나) ToonOut 만 (다) 위 섞기 규칙. 씨앗 400~411(개발), 412~423(확인).
3. 채택 기준: 체크무늬 변형에서 (다)가 (가)보다 모든 항목 평균이 같거나 높고 적어도 한 항목 +0.02, 기존 한 색 배경 벤치마크(68~79)에서 (다)가 (가)보다 0.01 넘게 떨어지는 항목 없음(한 색 배경이면 ToonOut 을 부르지 않으므로 같아야 정상). 새 머리·들소는 그림으로 확인(내 판단).
4. ToonOut 설치: SAM 처럼 따로 떨어진 환경(`.venv_toonout`), 작업자 하나(`tools/toonout_worker.py`: 그림 → 전경 확률 지도). 모델 파일 수백 MB 예상. 원격 전송·학습 없음.

## 왜 이렇게 섞나
- ToonOut 만 쓰면: 학습 모델이라 가는 뿔 끝·얇은 털을 지우거나 배경 조각을 붙일 수 있다(확인 전, 가설). 우리 규칙은 한 색 배경에서 이미 정확하다(합성 0.97 대).
- 우리 규칙만 쓰면: 체크무늬·그라데이션·복잡한 배경에 약하다(새 머리 남은 조각 298 → 고친 뒤 63, 아직 남음).
- 그래서 **쉬운 경우는 규칙, 어려운 경우만 학습 모델, 엇갈린 곳은 증거**로 가른다. SAM(작은 부위)·LLM(빠진 재질)도 같은 방식으로 이미 붙어 있다.

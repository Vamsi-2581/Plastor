# 모델링 설계도 형식(초안, 2026-10-29)

사용자 질문: "트레이싱 정보와 크로스 컨투어의 정보를 AI 모델링 설계도로 값을 쓸 수 있어?" → 쓸 수 있다. 3D 만들기는 이 설계도만 읽는다.
원칙: **숫자는 도구가 잰다, LLM 은 이름·종류·선택만 쓴다, 값마다 출처와 확신을 적는다, 만들기 전에 검사기가 설계도를 검사한다.**

## 구조
```json
{
  "도면": {"뷰": ["front", "side", "back"], "단위": "H", "출처_신뢰": "AI생성"},
  "부위": [
    {
      "이름": "뿔", "종류": "가늘어지는 둥근 관",
      "종류_출처": {"값": "LLM 피아식별", "두가족_일치": true},
      "좌우_짝": {"거울": true, "기준": "front"},
      "중심선": {"점": [[0.21, 0.05, 5.02], [0.45, 0.02, 5.18]], "출처": "트레이싱 가운데선(정면·옆 합침)", "확신": 0.9},
      "단면": [
        {"t": 0.0, "폭": 0.12, "깊이": 0.10, "모양": {"종류": "초타원", "지수": 2.0, "납작함": 0.83},
         "출처": {"폭": "정면 트레이싱", "깊이": "옆 트레이싱", "모양": "그림자 띠 법선"}, "확신": 0.8},
        {"t": 1.0, "폭": 0.02, "깊이": 0.02, "모양": {"종류": "초타원", "지수": 2.0, "납작함": 1.0},
         "출처": {"폭": "정면 트레이싱", "깊이": "옆 트레이싱", "모양": "이름 틀(가늘어지는 둥근 관)"}, "확신": 0.6}
      ],
      "붙는곳": {"부모": "머리", "자리": "위 옆", "박기_px": 8},
      "가정": [],
      "결정": []
    }
  ],
  "그림모순": [{"부위": "머리", "결정": "정면 따름", "근거": "옆 턱이 13px 아래"}]
}
```
- `t`: 중심선을 따라 0(뿌리) ~ 1(끝). 단면은 중심선에 수직.
- 단면 `모양`: 초타원 지수(2 = 타원, 클수록 각짐), 납작함(깊이/폭 외의 눌림). 크로스 컨투어(그림자 띠 법선) → 이름 틀 → 기본 타원 순서로 채운다(R1.5).
- `출처` 값: `정면 트레이싱`·`옆 트레이싱`·`그림자 띠 법선`·`그림 단면선`·`이름 틀`·`LLM 결정`·`가정`.

## 흐름
1. 트레이싱(원본 보관) → 의도 층(차이) → **설계도 채우기 도구**(가운데선·단면 폭·깊이 측정, 그림자 법선 → 단면 모양)
2. LLM: 이름·종류·짝·붙는 곳·그림 모순 결정만 채움(좌표 없음)
3. **설계도 검사**: 단면을 정면·옆에 비췄을 때 트레이싱 폭과 맞는지, 짝 대칭, 붙는 곳이 부모 표면 안인지 → PASS 면 만들기
4. 만들기(R1 매끈한 일반화 원통) → 3D 검사 → 어긋나면 해당 부위·단면으로 되짚음(역매핑)

## 검증 기준(돌리기 전에 정함)
- 합성 장면에서 설계도만으로 다시 만든 모델의 재투영 IoU ≥ 둥근 헐 − 0.01, 정답 부피 IoU > 둥근 헐.
- 설계도의 한 부위 단면만 바꾸면 그 부위 메시만 바뀜(다른 부위 지문 같음).

## 추가: 해부 정보와 투시 정보(사용자 "동시에 해부학과 투시정보도 생성하는 게 좋을 것 같아")
```json
{
  "해부": {
    "뼈_표지": [
      {"이름": "턱 경첩", "점": [0.0, 0.18, 4.72], "출처": "옆 트레이싱 턱선 꺾임 + 좌우 대칭", "확신": 0.6},
      {"이름": "뿔 뿌리", "부위": "뿔", "점": [0.21, 0.05, 5.02], "출처": "설계도 붙는곳", "확신": 0.9}
    ],
    "덮개_밑_몸": [{"부위": "머리", "덮개": "턱수염", "출처": "해부 보완(amodal)", "가정": true}],
    "비율": {"뿔길이/머리길이": 0.9, "출처": "설계도 측정"}
  },
  "투시": {
    "뷰": {
      "front": {"투영": "정사영", "1H_px": 150.5, "중심선_x": 321.5, "발바닥_행": 943, "투시_징후": 0.02, "빛_방향": [0.45, 0.55, 0.7], "빛_출처": "그림자 띠 경계"},
      "side":  {"투영": "정사영", "투시_징후": 0.08, "빛_방향": [0.40, 0.60, 0.69]}
    },
    "뷰_사이_어긋남": [{"뷰": ["front", "side"], "부위": "머리", "아래끝_px": 13}]
  }
}
```
- **해부**: 뼈 표지(머리뼈 중심·턱 경첩·목 관절·뿔·귀 뿌리)는 그대로 리깅 뼈 자리(R6·R7)가 된다. 위치는 도구가 트레이싱·대칭으로 재고, 이름은 LLM, 형태 사전에서 온 것은 가정으로.
- **투시**: 뷰마다 정사영인지(같은 부위 좌우 크기 차, 가로 안내선 평행), 축척·중심·발바닥, 빛 방향(그림자 띠 경계, R1.5). `투시_징후`가 크면 그 뷰는 정사영이 아니라고 보고 재투영 오차를 '모델링 오차'로 세지 않는다.
- **쓰임**: 형태 판단(턱이 아래로 내려온 게 그림 오류인지 입을 벌린 건지 — 턱 경첩 기준), 그림 모순(뷰마다 빛 방향이 다르면 근거 +1), 리깅(뼈 표지 → 뼈대).
- 검증: 합성 장면(정사영·빛 방향·뼈 위치를 앎)에서 빛 방향 오차 ≤ 10°, 일부러 투시를 넣은 뷰를 `투시_징후`로 가려냄, 뼈 표지 위치 오차 ≤ 0.05H.

## 한계와 알게 된 것 (숨기지 않음)

1. **1걸음 높이 이동량이 −0.521 로 크게 튀었다.** 민감도 표에서 높이 지표가 입력 핸들 둘에 걸쳐 잡음이 있었고(래스터 1픽셀 = 0.0067H), 2걸음부터 되돌아와 수렴했다. 50% 규칙이 있어도 첫 걸음은 거칠다.
2. **극점 지표는 불연속이다.** Hook 반경이 작아(0.45H) 돌기 일부만 움직이면 극점이 이웃 정점으로 넘어가 민감도가 0 이 되어 수렴하지 않았다. 반경을 돌기 전체(0.9H)로 키워서 해결했다. SKILL.md 에 규칙으로 적었다.
3. **민감도 걸음이 1픽셀보다 작으면 지표가 안 변한다.** 기본 걸음을 약 8픽셀(핸들), 0.1(격자 배율)로 했다. 격자 폭 복구는 6.9% 로 10% 한계에 가깝다. 폭 지표가 픽셀 둘(양쪽 가장자리)에 걸려서다.
4. **대상 밖 보존 검사가 약하다.** 보호 띠를 핸들 영향 범위 밖(윗머리, 뒤통수)에만 두어서 증가가 구조적으로 0 이다. 핸들 영향 가장자리 가까이 둔 보호 띠 시험은 아직 없다.
5. **핸들 오차 비교는 합성 형상 하나, 형상 하나뿐이다.** 일반 법칙으로 승격하지 않는다(범위: 타원체+돌기, 정면·옆 마스크, Hook 1개·Lattice 1개).
6. 자기 교차·연결부 단면 같은 3단계(들소) 검사, 3/4 사람 검토, Laplacian Deform 은 구현하지 않았다.

# 조사: 테크니컬 아티스트·그래픽스 개발자의 공개 발표·논문에서 가져올 관행 (2026-10-30)

사용자: "권위 있는 테크니컬 아티스트와 그래픽스 개발자들의 컨벤션이나 공개된 회의록, 논문 등 필요한 자료조사를 해줘".
표시: **확인** = 원문·공식 페이지에서 내용 확인, **요약만** = 검색 요약·2차 기사로만 확인(원문 미확인), **약함** = 업체 블로그·강좌 소개 수준.

## 2. 계획에 반영(루프 항목으로)
1. **부드러운 합집합 이음**(Quilez): 조립에서 부위끼리 만나는 곳만 smooth min. 기준(돌리기 전): 합성 확인 과제 부피·실루엣 하락 ≤ 0.005, 이음매 근처 거칠기 감소.
2. **편집 가능한 결과물 = 원형 기록**(Dreams): `fit_insts.json` 이 이미 원형 목록 → Blender 에서 원형마다 객체(타원체·커브 관)로 다시 만들어 슬라이더로 고치고 다시 맞추기(K7).
3. **리깅 준비 = 굽혀 보기 시험**(토폴로지 관행): 리토폴로지(QuadriFlow) 뒤 관절을 굽혀 늘어남·뒤집힘을 재는 자동 시험(K7).
4. **영향 뼈 ≤ 4·glTF 내보내기·Godot 로드**(K7 기준에 추가).
5. 몸 계획별 뼈대 템플릿(No Man's Sky·Spore 식) — K7/K9, 원문 확인 뒤.

# 하네스 수정 기록 (사람 지적 → 일반 규칙 → 회귀 시험)

원칙: 사람이 그림을 보고 지적한 것은 **이 도면만 고치지 않는다.** 지적마다 다음 넷을 남긴다.
1. 증상(그림에서 본 것), 2. 원인(측정으로 확인한 것), 3. 일반 규칙(어느 도면에나 적용되는 말), 4. 회귀 시험(합성 도면, 끝 코드로 판정).
시험 없이 고친 규칙은 다음 도면에서 다시 깨진다. 시험이 아직 없으면 그 칸에 **없음**이라고 쓴다.

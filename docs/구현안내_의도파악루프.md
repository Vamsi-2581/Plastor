# 구현 안내: 의도 파악 루프(형태 판단 R2.5) — 새 세션용

설계: `docs/설계_형태판단.md` 2·3·6장. 규칙: `CLAUDE.md`(한국어, 판정 넷, 좌표 안 받는 도구, 기준은 돌리기 전에). 파이썬은 Blender 번들 `"/c/Program Files/Blender Foundation/Blender 5.2/5.2/python/bin/python.exe"`.

## 0단계: 원본 트레이스 보관
- trace 결과를 `<out>/masks_raw.npz`(그림 그대로)로 따로 저장하고, 의도 파악이 바꾼 결과는 `masks.npz` + 차이 기록(`intent_diff.json`: 조각·뺀 픽셀·근거). 되돌리기 명령 `intent_revert`.

## 1단계: 오류 주입 벤치마크 (`bench/scene.py`, `bench/run.py`)
- `render(..., inject=None)` 옵션. 정답 마스크(truth)는 그대로 두고 **그림만** 바꾼다.
  - `'twin'`: 옆 뷰에서 뿔 영역(정답 마스크)을 복사해 가로로 25~40px(씨앗 난수) 비켜 붙임 = GPT 가 반대편 뿔을 비켜 그린 경우.
  - `'clutter'`: 다른 씨앗 장면의 머리 조각을 패널 가장자리에 붙임 = 옆 그림 조각이 끼어든 경우(새 머리 도면).
  - `'asym'`(의도된 특이함): `creature()` 에서 오른쪽 뿔만 1.3 배(3D 에서, 모든 뷰 일관) → **고치면 안 되는** 경우.
- 주입한 픽셀 마스크를 반환해 채점에 쓴다(`truth_inject`).
- `cached_render(..., inject=)`, `scene_case(..., inject=)`, `compare_cfg.py --inject twin|clutter|asym` 까지 연결.

## 2단계: 조각·증거 (`harness/intent.py`, 새 파일)
- `pieces(masks, mat, views)`: 부위·뷰마다 마스크의 연결 성분(≥ 30px). 가장 큰 것(정면의 좌우 짝 부위는 큰 두 개)이 '본체', 나머지는 후보. 트레이스의 덧붙임(added) 영역도 후보.
- `evidence(piece, masks, frame)` → 숫자만(도구가 잼):
  - `E1_높이지지`: 후보의 행 중 다른 뷰에서 같은 부위가 있는 행 비율.
  - `E2_거울`(정면·뒤): 후보를 대칭축으로 뒤집은 자리가 같은 부위와 겹치는 비율.
  - `E3_연결`: 같은 부위 본체와 맞닿는지(0/1).
  - `E3_짝규칙`(옆 뷰): 정면에서 좌우 짝인 부위가 옆에서 본체 말고 **크기가 비슷한 덩어리**를 하나 더 가지면 1(정사영이면 짝은 겹쳐 보여야 함).
- `inspect(piece)` → 그림 셋(확대 3배 + 후보 테두리, 다른 뷰 같은 높이 띠, 정면 거울 자리)과 위 숫자를 폴더에 저장.

## 3단계: 질문·합의 (`trace_review.py` 명령 `intent` / `intent_merge`, `harness/api.py` 도구 `intent`)
- `intent`: 후보마다 `inspect` 그림 + 객관식 질문 파일 두 개(보기 순서 A·B). 보기: 이 부위 / 다른 부위 / 반대편 짝 / 배경·옆 그림 / 그림자·무늬 / 그림 오류 / 모르겠음. 현재 답을 보여 주지 않는다.
- 답: Claude 쪽(하위 에이전트 Sonnet, 순서 A)과 Codex(`codex exec`, 따로 떨어진 사본, 순서 B). 형식 `{"answers": [{"id": n, "답": "..."}]}`.
- `intent_merge`(resolve): 후보를 부위에서 **뺀다** ⇔ (두 답이 같고 '이 부위'가 아님) **그리고** (E1_높이지지 < 0.5 / E2_거울 < 0.3 / E3_연결 = 0 / E3_짝규칙 = 1 중 **둘 이상**). 두 답이 같고 '이 부위'이면 둔다. 나머지는 UNKNOWN(그림 그대로) + 사람 목록. 결정은 결정 기록 형식(부위·종류·결정·근거)으로 쓴다.

## 4단계: 검증(기준은 설계 6.3·3장, 돌리기 전에 정함)
- 씨앗: 개발 500~511(twin·clutter·asym 각 4), 확인 512~523.
- 채점: 후보마다 정답(주입 픽셀이 후보의 50% 이상 → 오류 조각, 아니면 정상). 정밀도(뺀 것 중 오류 조각) ≥ 0.9, asym 오교정률 ≤ 0.05, 재현율 ≥ 0.6, 확정 비율 ≥ 0.7, 도면당 질문 ≤ 40, 기존 벤치마크(68~79) 트레이스 IoU 하락 없음.
- 실제 도면: 들소(옆 반대편 뿔), 새 머리(옆 그림 조각·라벨)에서 후보·결정을 그림으로 확인.

## 부록: 트레이싱 ↔ 의도 매핑(사용자 질문 "트레이싱에 의도 추론을 매핑할 거야?")
- **의도 층**: 트레이싱과 같은 픽셀 좌표의 조각 번호 지도(`intent_pieces.npz`: 뷰마다 조각 번호) + 조각별 기록(`intent_records.json`: `{id, 뷰, 부위, 픽셀 수, 답(피아식별), 증거 숫자, 두 가족 답, 결정(유지/뺌/더함/UNKNOWN), 근거}`).
- **최종 마스크 = 원본 트레이스(`masks_raw.npz`) ⊕ 의도 층 결정**. 의도 층을 끄면 원본. 겹침 그림: 더함 보라, 뺌 청록, UNKNOWN 회색 테두리.
- **역매핑(3D → 트레이스)**: 3D 검사(재투영 오차·상자 단면 등)의 오차 픽셀을 뷰별로 모아, 오차가 가장 많이 겹치는 트레이스 조각을 의도 파악 후보로 다시 올린다(`attribute(model_check) → 조각 번호 목록`). 루프: 트레이스 → 의도 → 3D → 검사 → 해당 조각.

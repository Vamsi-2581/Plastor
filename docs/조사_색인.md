# 조사 색인: 무엇을 조사했고, 어디에 쓰였고, 어디에 쓸 것인가 (2026-10-29)

사용자: "지금까지 조사한 게 헛되지 않았으면 좋겠어요". 조사 하나하나를 **쓰인 곳(하네스 기능·커밋)** 또는 **쓸 곳(로드맵 단계)** 에 묶는다. 새 일을 시작할 때 이 표부터 본다.

## 루프 순서 원칙(사용자 "먼저 정확한 트레이싱을 하고 그걸 다듬어 가는 게 옳지 않나")
1. **정확한 트레이싱(그림 그대로)** 을 먼저 만들고 `원본 트레이스`로 따로 보관한다.
2. 형태 판단·의도 파악은 그 위에서 **바꾼 부분만(차이)** 기록하는 다듬기 층이다. 근거가 없으면 바꾸지 않는다.
3. 다듬은 결과는 언제든 원본과 비교하고 되돌릴 수 있다.

## 별도 AI 없이 구독 LLM(Claude Code 등)만으로 하는 연구·프로젝트(2026-10-29 조사)
| 이름 | 방식 | 우리와의 관계 |
|---|---|---|
| CAD-Assistant(ICCV 2025, [arXiv 2412.13810](https://arxiv.org/abs/2412.13810v1)) | 학습 없음. GPT-4o 가 계획, FreeCAD 파이썬을 실행하며 결과를 보고 다음 걸음. 손그림 매개변수화·제약 분석·단면 도구, 도구 추가는 설명문(docstring)만 | **우리와 가장 같은 철학**(LLM + 정해진 도구 + 실행 되먹임). 도구 설명만으로 도구를 늘리는 방식은 우리 도구 층에 바로 맞음 |
| LL3M([ResearchGate](https://www.researchgate.net/publication/394439477_LL3M_Large_Language_3D_Modelers)) | 학습 없음. 여러 에이전트가 Blender 코드를 쓰고, 비평 에이전트가 렌더를 보고 고칠 곳을 돌려줌. 자산을 부위별 모듈 코드로 둬서 국소 수정 | 부위 그래프(R2)·비평(R4)과 같은 구조 |
| BlenderRAG([arXiv 2605.00632](https://arxiv.org/pdf/2605.00632)) | 미세조정 없이 아무 LLM API 에 Blender 문서 검색을 붙임 | 교훈·문서 검색(기억 틀) |
| Planner-Actor-Critic([arXiv 2601.05016](https://arxiv.org/pdf/2601.05016)) | MCP 도구로 Blender 를 몰고, 비평은 **3번쯤에서 더 나아지지 않음** | 루프 횟수 한도의 근거(같은 진단 2번이면 조사 단계로 넘기는 지금 규칙과 맞음) |
| aDSL(학습 없음, 관계 연산), SceneCraft, BlenderAlchemy | 학습 없이 상용 LLM + 프로그램·렌더 되먹임 | 이미 색인에 있음 |
| **Anthropic 공식 Blender 연결기**(2026년 4월, Blender 개발진이 만든 MCP 연결기를 Claude 용으로 공식 제공, Anthropic 이 Blender 개발 기금 후원, [Digital Production](https://digitalproduction.com/2026/04/30/anthropic-funds-blender-ships-claude-connector/), [Forklog](https://forklog.com/en/news/anthropic-integrates-claude-with-blender-adobe-photoshop-and-premiere)) | 파이썬 API 로 장면 읽기·고치기·스크립트 | 지금 쓰는 MCP for Blender(개인 프로젝트)보다 공식판이 낫다면 바꿀 후보(원격 전송·기능 비교 필요) |
| Claude Code 용 Blender 스킬(예: [kevinbadi/blender-skills](https://github.com/kevinbadi/blender-skills)) | 그림 → 3D 는 Meshy 같은 **유료 외부 생성 AI** 를 부름 | '별도 AI 없이'가 아님. 도면 충실도 검사도 없음 |

결론: 구독 LLM + 정해진 도구 + 실행 되먹임으로 3D 를 만드는 연구는 여럿 있다(CAD-Assistant·LL3M·aDSL·BlenderRAG). 하지만 **정사영 크리처 도면을 충실하게 따라 만들고, 검사기가 판정하는 것**을 하는 공개 프로젝트는 찾지 못했다. 이 하네스가 그 자리를 채우는 것이다.

# synth_basic 기준선 1 (하네스 없이 자유 제작)

- 만든 것: 부위별로 닫힌 메시 6개를 한 OBJ 에 넣음(꼭짓점 11660). 스크립트 `make_model.py`.
  - 머리: 타원체 1개 (중심 0, 0.10, 4.80 / 반지름 0.307, 0.30, 0.40). 도면 확대 크롭에서 눈대중으로 잰 값.
  - 주둥이: 타원체(거의 구) 1개. 귀 2개: 납작한 타원체(좌우 대칭).
  - 뿔 2개: 정면 화면 좌표로 찍은 제어점(Catmull-Rom 곡선) 따라 타원 단면 튜브. 반지름은 밑동에서 끝으로 가늘어지고 끝은 뾰족하게 닫음. 옆면에서 읽은 앞뒤(Y) 값을 제어점마다 줌. 오른쪽 뿔은 X 반전.
  - 목·갈기: 만들지 않음(도면에 갈기 없음).
- 고친 횟수: 1회 (뿔 밑동 두께·아래쪽 제어점 약간 조정).
- 스스로 본 문제:
  - 뿔 아래쪽(머리와 만나는 부분)이 도면보다 조금 얇고 위로 붙음. 뿔 안쪽 곡선은 거의 일치.
  - 귀의 앞뒤 위치(Y)는 옆면에서 머리에 가려 보이지 않아 머리 중심 근처로 추측함.
  - 도면 해석에 쓴 치수는 눈대중(확대한 그림 + 격자)이라 +-3px 정도 오차 가능.
  - 렌더 비교는 정면·옆 실루엣 윤곽을 도면에 겹쳐 봄(check_v0.png, check_v1.png).

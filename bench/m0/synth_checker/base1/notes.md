# synth_checker 기준선 1 (하네스 없이 자유 제작)

- 만든 것: 부위별로 닫힌 메시 8개를 한 OBJ 에 넣음(꼭짓점 13512). 스크립트 `make_model.py`(synth_basic 것과 같은 도구 함수).
  - 머리: 타원체 1개 (중심 0, 0.13, 4.84 / 반지름 0.31, 0.31, 0.356).
  - 주둥이: 타원체 1개(정면 타원 53x43px). 귀 2개: 납작한 타원체.
  - 갈기: 옆면에서 머리 뒤 위쪽에 겹쳐 보이는 큰 타원체 1개(중심 Y=-0.325). 정면에서 머리 위로 솟은 윤곽과 맞음.
  - 이마 앞머리 뭉치: 작은 타원체 1개(옆면 머리 윗면의 혹, 정면의 작은 돌기).
  - 뿔 2개: 정면 화면 좌표 제어점(Catmull-Rom 곡선) 따라 가는 타원 단면 튜브, 끝은 뾰족하게 닫음. 옆면에서 읽은 앞뒤(Y)를 제어점마다 줌. 오른쪽 뿔은 X 반전.
  - 목: 만들지 않음.
- 고친 횟수: 1회 (뿔이 도면보다 가늘어서 밑동 반지름과 가늘어지는 지수 조정).
- 스스로 본 문제:
  - 갈기가 따로 있는 것인지 목 위쪽인지 도면만으로 확신 못 함. 옆면의 둥근 혹을 갈기로 보고 타원체로 처리함. 정면 폭(0.36)은 윤곽에 맞춰 추정.
  - 앞머리 뭉치는 모양이 불분명해 작은 타원체로 대충 처리, 위치가 틀렸을 수 있음.
  - 귀의 앞뒤 위치(Y)는 머리에 가려 안 보여 추측.
  - 뿔이 도면보다 약간 두껍게 나옴. 머리 옆 윤곽은 맞지만 머리와 갈기 사이 오목한 부분은 도면에 목이 겹쳐 있어 비교 불가.
  - 비교는 정면·옆 실루엣 윤곽을 도면에 겹침(check_v0.png, check_v1.png).
